# Run multiple Claude Desktop accounts on Windows

Keep personal, work, and client desktop sessions in separate local folders, with recognisable launchers.

## How to create a profile

Open Hatrack, choose Create profile, select Claude Desktop, and enter a name. Choose an icon and your shortcuts, create the profile, then launch it and sign in. New profiles do not inherit your original login.

## Automatic detection and manual selection

Hatrack looks for the registered Claude Windows package and standard locations. If it is missing, use the official download link. If detection misses an installed copy, use Locate app and select the official Claude desktop executable.

## Existing profiles

Find existing profiles lists candidate folders. Import only the correct profile; original shortcuts are preserved. The same vendor executable may serve multiple profiles, while their local data folders remain separate.

## What is verified?

The preview implements separate user-data and cache launch arguments. Independent authenticated sessions, restart persistence, and vendor-update behaviour require recorded acceptance before stable compatibility is claimed.
