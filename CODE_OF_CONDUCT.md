# Code of conduct

Hatrack is a small open-source project. Everyone who takes part in issues, discussions and pull requests is expected to:

- Be respectful and assume good intent. Critique code and ideas, not people.
- Keep discussion on topic and useful to the people reading it.
- Never post other people's personal data, account details, tokens or private conversations.
- Not harass, insult, or discriminate against anyone for any reason.

The maintainer may edit or remove comments, close threads, or block accounts that break these rules. Report a problem privately through GitHub's **Report content** option or the contact on the maintainer's GitHub profile.
