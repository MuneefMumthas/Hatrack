# Hatrack

Personal open-source desktop profile manager by Muneef Mumthas. MIT copyright belongs to the author for original work. Windows 11 x64, Claude Desktop and Codex Desktop only. No CLI substitution, no UNEEVERSE branding. The latest user request authorizes exact vendor logos as colourable profile icon presets. The Hatrack product identity remains original and independent. No telemetry or Hatrack account.

People managing personal, work, and client accounts need recognisable, independently persisted desktop sessions without terminal setup. Automatically discover official applications and existing profiles, with validated manual locations. Preserve existing profiles and shortcuts. New profiles get immutable IDs and separate local data. Sign-in occurs in the official app.

Approved direction: monochrome, rounded, and precise, with the craft level of Apple and Revolut Wallet. Black and white control surfaces, clear light/dark/system themes, custom dropdowns, buttons, inputs, sliders, checkboxes, expandable image controls, and a custom colour picker. Colour belongs to profile logos. No glows, em dashes, vague slogans, or invented popularity claims. The Hatrack logo is monochrome: a top hat on an upper shelf above two bowlers on a lower shelf. New profile defaults use the matching Claude or Codex mark, recolourable without changing its silhouette; legacy profile icons remain intact. Code-led implementation follows this explicit visual direction. The website shows the real interface and uses practical copy.

Release gates: independent desktop authentication/state for both vendors; no data loss or overwritten shortcuts; install/upgrade/remove tests. Until gates are evidenced, ship a local unsigned preview and block stable publication. Untested vendor app versions ask for confirmation once per version instead of blocking launch, because vendor apps update often. Hatrack was named Profiles until 0.2.0; pre-rename data folders, shortcuts and taskbar IDs keep working.
